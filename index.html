How this works
Weeks 1–3 keep the weight and add reps. Week 4 bumps the weight and drops back to the bottom of the rep range, then week 5 builds the reps again. Week 6 is a lighter week with fewer sets so you recover and come back stronger. When you finish week 6, start the next block and every weight goes up one step.

Logging: type the kg and reps for each set. The grey numbers are today's target, so leave a box empty only if you skipped that set. An exercise ticks itself once every set has reps. Use the notes box for anything else.

If a target is too hard: stay on the same weight and reps next week instead of going up. If it felt easy (3+ reps left), jump ahead a week for that exercise.

Knee: keep everything pain-free. Drop weight before you drop form.
